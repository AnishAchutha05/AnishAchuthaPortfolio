Multi-agent systems

SWARM

SWARM virtualises a single LLM into 5–20 ephemeral agents, each with a distinct cognitive role. They reason in parallel through a shared blackboard memory. Agents are spawned based on query complexity, scored against each other and pruned after every task, so the system reorganises itself around the problem.

Browser agents · Privacy

Cyclops

A privacy-first browser agent. It reads pages DOM-first with vision assistance, then detects and redacts PII locally. Only sanitised context goes to remote LLMs and VLMs for reasoning, while sensitive data and every browser action stay on the device.
